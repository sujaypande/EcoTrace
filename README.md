# EcoTrace

EcoTrace is a smart e-waste collection and recycling platform that helps users responsibly dispose of electronic waste through pickup scheduling, recycling center discovery, and transparent waste tracking.

## Getting Started

1. Copy `.env.example` to `.env.local` and fill in your values.
2. Install dependencies: `npm install --legacy-peer-deps`
3. Run the development server: `npm run dev`
4. Open [http://localhost:3000](http://localhost:3000)

## Environment Variables

See `.env.example` for required configuration.

## Production Build

```bash
npm run build
npm run start
```
